 # What is Claude?

 Claude is an AI coworker that helps you finish real work faster — writing, research, coding, planning, or learning. You give context and goals; Claude returns usable drafts, explanations, or plans.

 ## Getting started (quick)

 1. Say who you are and what you want. Example: "I'm a product manager preparing a feature brief. Help me outline the 5 key points." 
 2. Specify format and length. Example: "Make a short bullet list for an executive summary (5 bullets)."
 3. Set tone. Example: "Keep it friendly and professional."
 4. Attach relevant files (PDF, DOCX, CSV, images) when you need Claude to use source material.

 ## Starter prompts you can copy

 - "Summarize this doc in 5 bullets and suggest next steps." 
 - "Draft a concise follow-up email asking for an update." 
 - "Explain this code block in plain English and point out one improvement." 

 ## What Claude does (at a glance)

 - **Write:** drafts, edits, summaries, and templates.
 - **Research:** pull key points, compare options, summarize quickly.
 - **Code:** generate examples, explain behavior, spot likely bugs.
 - **Plan:** outline projects, estimate steps, weigh trade-offs.
 - **Teach:** step-by-step explanations and small practice exercises.

 ## How to get better results

 - Be specific: audience, length, and example output help a lot.
 - Give source files when accuracy matters.
 - Iterate: ask for revisions, different tones, or a shorter version.
 - Ask Claude to list assumptions when you need transparency.

 ## Personalizing Claude — make it feel familiar

 Imagine telling a helpful coworker once who you are and how you like work done — and then never repeating it. That’s Memory.

 - **Memory:** Automatically remembers useful context (your role, preferences, past decisions) so Claude tailors replies without repeating yourself. Example: tell Claude "I work in B2B marketing," and future outputs will reflect that perspective. You control memory — review, edit, or delete items anytime in Settings; it syncs across your devices.

 - **Styles:** Let Claude speak in a voice you prefer. Pick presets like *concise*, *explanatory*, or *formal*, or define a custom style by describing how you want sentences, tone, and pacing to feel. Once set, your style applies across chats for consistent output.

 Think of Memory + Styles as your personal prompt shortcuts: they save time and make results feel like they came from you.

 ## Limits & safety

 Claude helps a lot but can be wrong. Always verify critical facts and test code before using it in production.

 **Pro tip:** Save a short template prompt (role + task + tone) you reuse — it gets you reliable, repeatable results.

 Clear, concise instructions plus a little context make Claude most useful — not long essays, just precise direction.
